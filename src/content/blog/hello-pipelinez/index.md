This is placeholder content for the new blog gallery. It exists only to check that the
gallery grid, the individual post page, and the hero image all render correctly with real
data — it is deleted once the actual first post is written (see Task 9 of the implementation
plan this came from).

## Why a placeholder?

Building a gallery against zero posts makes it easy to miss layout problems that only show
up once there is a card to look at: image aspect ratio, title wrapping, excerpt length, and
date formatting all need at least one real-looking entry to check.

## What's next

Once this renders correctly on `/blog/` and at this post's own URL, this file and its hero
image are deleted, and the gallery goes back to showing its empty state until the first real
post is published.
